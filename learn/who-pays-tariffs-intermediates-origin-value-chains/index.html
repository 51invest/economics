关税落在谁头上：中间品、原产地与价值链

关税的法定纳税人是进口商，经济负担却由消费者、进口商、出口商和上游供应商分担。中间品、原产地规则和价值链会把一个看似简单的税率放大成有效保护率、合规成本和双重征税。本文用有效保护率和一个三国价值链算例，拆开“关税落在谁头上”。

定义与直觉

关税是对跨境商品征收的税[1]。法定纳税人是进口商，但经济负担不一定由进口商承担。如果进口国需求弹性低、出口国供给弹性高，进口商可以把大部分税负转嫁给国内消费者；如果进口国需求弹性高、出口国有替代市场，出口商可能被迫降价，负担落在出口国生产者。incidence（税负归宿）问的就是“谁最终少拿了钱”，不是“谁去海关交税”。

有效保护率（effective rate of protection, ERP）把最终品关税和中间品关税合在一起。其逻辑是：关税保护的是国内增加值，不是总产值；如果中间品也要交税，保护被削弱。公式为 ERP = (t_f − a·t_i)/(1 − a)，其中 t_f 是最终品税率，t_i 是中间品税率，a 是中间品成本占最终品产值的比例。

原产地规则决定一件商品能不能享受协定税率。它通常要求“实质性改变”，但实质性改变的标准可以是税则归类改变、区域价值成分或特定工序。规则越复杂，合规成本越高；低税率可能被原产地文件、审计和追溯成本吃掉。

三种价格效应

关税至少产生三种价格效应：

  1. 名义保护：最终品关税直接抬高进口品价格，给国内同类生产者一个价格伞[2]。
  2. 有效保护：中间品关税抬高投入成本，抵消一部分最终品保护；如果中间品税率高于最终品税率，有效保护率可能为负。
  3. 合规成本：原产地证明、供应链追溯、海关估价和反规避调查，都是按货值或按票计算的固定成本；对小批量、多品种的企业，合规成本占比更高。

这三种效应叠加后，同一个 10% 的名义税率，对不同企业可能是 15% 的有效保护、5% 的有效保护，甚至是负保护。只看税则表上的税率，会误判产业受到的保护。

正式表达与示例

假设一件最终品价值 100 元，其中中间品成本 50 元，国内增加值为 50 元。最终品关税 t_f = 20%，中间品关税 t_i = 5%。代入公式：

ERP = (0.20 − 0.5×0.05)/(1 − 0.5) = 0.35，即 35%。

名义税率只有 20%，但国内增加值受到的保护是 35%，因为中间品只被轻税。若中间品税率升到 20%，ERP = (0.20 − 0.5×0.20)/0.5 = 20%，保护回到名义水平。若中间品税率升到 30%，ERP = (0.20 − 0.15)/0.5 = 10%，保护被削掉一半。

再看原产地。假设三国价值链：A 国出口中间品到 B 国加工，再出口到 C 国。C 国对最终品征 10%，但原产地规则要求区域价值成分达到 60%。B 国加工只增加 35% 价值，达不到门槛，最终品按 10% 征税；如果企业为了达标把采购从 A 国转到成本更高的 C 国供应商，合规成本就变成了新的贸易壁垒。以上数字均为教学假设。

分配效应

关税的负担至少分给四类人：进口国消费者面对更高价格；进口商承担库存、汇率和合规风险；国内生产者获得价格伞，但可能付出更高的中间品成本；出口国生产者可能被迫降价或失去市场。政府获得关税收入，这部分可以用于补偿受损群体，也可以变成财政一般收入。

分配效应还跨部门[4]。对最终品征关税，保护的是最终品生产者；对中间品征关税，保护的是中间品生产者，却伤害使用中间品的下游。若下游是劳动密集、出口导向的行业，关税可能在保护上游的同时减少下游就业。判断一项关税“保护了谁”，要把上下游的就业和利润一起看。

消费者剩余的损失通常大于生产者剩余和关税收入之和，差额是效率成本；但效率成本不是全部，还要看分配是否可接受、调整是否可逆。一个总剩余略降但保护了特定地区的关税，可能在政治上通过，在经济上低效。

政策设计

如果目标是保护国内增加值，而不是保护上游租金，政策设计应遵循三条：

  1. 最终品与中间品税率要匹配。 对最终品高税、对中间品低税，会提高有效保护；反过来会形成负保护，惩罚下游。
  2. 原产地规则要与能力匹配。 区域价值门槛过高，小企业无法达标；税则改变标准更简单，但可能被轻微加工规避。规则设计要在防规避和可合规之间取平衡。
  3. 配套调整援助。 关税会重新分配就业和利润，受损群体需要培训、转移支付或区域政策；没有 adjustment assistance，保护会变成长期补贴。

关税不是唯一工具。配额、技术标准、补贴和政府采购也能保护国内产业，但它们的租金归属、透明度和合规成本不同；选择工具时要一起算。

适用条件与边界

关税分析有四个容易忽略的边界：

弹性决定归宿。 需求弹性越低、供给弹性越高，税负越容易转给进口国消费者；反之，出口商承担更多。简单说“关税由进口商付”只描述了法律关系。

中间品会重复计税。 全球价值链中，同一笔价值可能多次跨境，每次都被征一次关税；累积税负可能远高于单看最终品的税率[3]。

原产地规则有战略用途。 规则可以防止转运规避，也可以被用来把竞争对手排除在优惠区之外；判断规则是否“必要”，要看它是否与防止规避成比例。

汇率与一般均衡会反馈。 关税可能推高进口国物价、压低出口国汇率，进而改变贸易量和税负分担；局部算例不能替代一般均衡分析。

常见误解

误解一：关税全由进口商承担。 进口商只是法定纳税人；税负归宿取决于相对弹性。

误解二：名义税率就是保护程度。 中间品关税会改变有效保护率；负保护并不罕见。

误解三：原产地规则只是行政手续。 规则设计会改变采购地、生产工序和投资地点，是实质性的贸易政策工具。

深化：关税归宿、原产地与中间品

关税名义上由进口商缴纳，经济上由谁承担取决于议价和替代。若进口商能把成本转给消费者，且消费者没有替代品，关税主要由消费者承担；若消费者可以转向国产或第三国产品，进口商和出口商会分担；若出口商降价保市场份额，则由出口国承担。汇率调整也会吸收一部分。

中间品让归宿更复杂。一个零部件被征关税，下游制造商成本上升；若下游再出口，关税可能变成“出口税”，损害本国竞争力。全球价值链越深，关税越容易重复计征、越难追溯。

原产地规则决定“哪里制造”。实质改变标准、区域价值含量和累积规则，会让同一产品在不同协定下税率不同；企业可能调整供应链、转口或增加本地加工，成本可能高于关税本身。

2018—2019 年中美关税的经验：研究普遍发现关税成本大部分转给美国进口商和消费者，但转嫁程度因产品、替代性和时间而异；受影响的行业就业和投资下降，供应链在多年内重组。

政策评估不能只看关税收入。要看消费者价格、生产者成本、供应链重组、贸易转移和报复；关税是谈判工具，也是产业政策工具，目标不同，评价标准不同。

常见误用：把“关税由外国出口商支付”当成事实；把关税收入当成净收益；忽略中间品和原产地规则的合规成本。

反证条件

关税归宿的结论依赖三个环节，任一环节变化都要重算：

  1. 进口商是否吸收。 若进口商压缩利润而非提价，消费者承担的比例下降，关税更像利润税。
  2. 原产地规则是否可绕开。 若转口和微小加工被允许，关税覆盖被高估，实际保护低于名义税率。
  3. 中间品是否被排除。 若关税只覆盖最终品，有效保护率与名义税率差异很大；中间品加税会叠加成本。
  4. 汇率是否调整。 若本币贬值抵消关税，进口价格和贸易余额的短期反应会被削弱。

把“谁进口、原产地在哪、中间品多少、汇率怎么动”四件事拆开，才能判断关税到底打中了谁。

反证条件（续）

还有一项：关税是否被配额或许可证替代。 若数量限制取代关税，价格效应和租金分配会完全不同，单看税率会低估保护程度。

判读补充

关税分析还要区分“名义税率”和“有效保护率”。中间品被征税会抬高下游成本，原产地规则又决定哪些投入算境内；同样 10% 的关税，对本地增加值高的产品保护更强，对组装出口的产品可能只是成本转嫁。判断谁承担，要看价值链位置、替代性和汇率反应，而不是只看出口岸价格。
